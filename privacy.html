Sentence Workshop — Privacy

Updated 10 October 2026.

Sentence Workshop is a grammar practice app. Sentence checking happens in your browser using rules. There is no AI checking, advertising or analytics.

Temporary open testing

During beta testing, all lessons, activities and reviews can be used without signing in. Google sign-in and synchronization are suspended. One testing profile, including current work, answers, scores, corrections and progress, is stored locally in this browser under a separate testing key. This profile is shared by people using the same browser profile on this website and does not follow you to another device. Existing Google caches and older local profiles are left untouched and are never automatically selected or uploaded.

Reloading restores local testing work when browser storage is available. If saving is blocked or fails, the app reports it and work remains in the current page. Save backup downloads the current testing profile; backup import is available only in standard mode. Clearing browser data removes local testing progress. Sign-in and sequential access rules will be reinstated when testing ends.

Google sign-in in standard mode

The retained standard mode requires Google sign-in for the saved course. When enabled and used, the app receives your Google account identifier, name and email. The email identifies the account on screen. The name, account identifier, sentence and parts-of-speech identification attempts, task requirements, scores, corrections, chapter access, lesson readiness, review attempts, recovery practice, paused reviews and current activity are saved in Google Drive’s hidden application-data folder and in an account-specific local browser cache. The app requests access to application data, not general access to your ordinary Drive documents. Browser-only testing progress is not automatically uploaded when standard mode returns.

The app keeps its Google access token in memory during the session and does not save that token in browser storage or backups. It asks you to select your Google account on each visit. Work is synchronized to the same Google account on another supported device. Use one active device or tab at a time. Signing out hides the account and its work; the account-specific cache remains on this browser so an interrupted save can be recovered after signing in again. Clearing browser storage deletes that local cache.

While signed in, a student can explicitly import a backup containing only their own profile. A class backup containing multiple profiles cannot be uploaded to one Google account. Save backup contains only the signed-in account’s profile. The Progress backup menu is available only while signed in.

First submitted answers and original skipped/unscored review questions are retained, including when a replacement question is used. Earned progress is preserved when later work is weaker. A teacher-help suggestion after repeated unsuccessful reviews does not send messages or share records with a teacher.

Where information goes

Open testing saves progress in this browser and does not contact Google sign-in or Google APIs. In standard mode, Google handles sign-in and stores synchronized progress. Sentence Workshop uses its own Google OAuth configuration and named application-data files. It does not read or change FactFlow progress. There is no separate application database and no teacher spreadsheet reporting in Sentence Workshop.

Your choices

You can save a JSON backup, sign out, remove the app’s access through your Google account permissions, clear browser data, or remove application data through Google Drive’s app-management settings. Removing access does not by itself guarantee deletion of already saved data. Removing application data deletes saved cloud progress; save a backup first. Ask your teacher before doing this on a school account.
