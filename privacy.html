Sentence Workshop — Privacy

Updated 8 October 2026.

Sentence Workshop is a grammar practice app. Sentence checking happens in your browser using rules. There is no AI checking, advertising or analytics.

Local practice

You can practise without Google sign-in. Named local profiles store work in this browser. Local profiles are not password protected; choose only your own name on a shared computer. Anonymous practice is not saved after closing the page.

Google sign-in and saved progress

Google sign-in is optional. When you use it, the app receives your Google account identifier, name and email. The email identifies the account on screen. The name, account identifier, sentence attempts, task requirements, scores, corrections and current activity are saved in Google Drive’s hidden application-data folder and in an account-specific local browser cache. The app requests access to application data, not general access to your ordinary Drive documents.

The app keeps its Google access token in memory during the session and does not save that token in browser storage or backups. It asks you to select your Google account on each visit. Work is synchronized to the same Google account on another supported device. Use one active device or tab at a time. Signing out hides the account and its work; the account-specific cache remains on this browser so an interrupted save can be recovered after signing in again. Clearing browser storage deletes that local cache.

No local profile is automatically copied to Google. A student can explicitly copy their selected local profile or import a backup containing their own profile. A class backup containing multiple profiles cannot be uploaded to one Google account. A backup saved while signed in contains only that account’s profile.

Where information goes

Google handles sign-in and stores synchronized progress. This version uses the existing FactFlow Google OAuth project; Sentence Workshop uses its own named application-data files and does not read or change FactFlow progress. There is no separate application database and no teacher spreadsheet reporting in Sentence Workshop. Network requests are limited to Google sign-in and Google APIs.

Your choices

You can save a JSON backup, sign out, remove the app’s access through your Google account permissions, clear browser data, or remove application data through Google Drive’s app-management settings. Removing access does not by itself guarantee deletion of already saved data. If Google identifies the shared OAuth project as FactFlow, removing that project’s access or application data can affect other apps in that project as well. Ask your teacher before doing this on a school account.
